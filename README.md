# 아델라인 글로벌 (Adeline Global Trade)
## 해외영업 진행 프로세스 (Order Process SOP) & 브랜드사 관리 시스템

아델라인의 무결점 해외 무역 수출입을 위한 SOP 8단계 순차 공정 제어 및 브랜드사 통합 허브 시스템입니다.

### 🚀 주요 기능
1. **SOP 8단계 순차 워크플로우 엔진**
   - Step 1: 바이어 주문 접수 (주문서 수령 / Draft CI 작성 / 바이어 확정)
   - Step 2: 브랜드사 발주 (발주서(PO) 전달 / 브랜드사 확정서 수령 크로스체크)
   - Step 3: 바이어 최종 확인 및 입금 요청 (Final CI / 송금 요청 / SWIFT Copy / **★ 아델라인 대표님 실제 입금 확인 승인**)
   - Step 4: 브랜드사 결제 (대표님 결제 승인 / 브랜드사 입금 / Packing List(PL) 수령 / Final CI·PL 대조)
   - Step 5: 선적서류 작성 및 수출면장 (Final CI·PL 전달 / **⚠️ 최종 패킹 확정 원칙 가이드** / 관세사 수출면장 및 C/O 요청)
   - Step 6: 입출고 진행 (브랜드사 -> 아델라인 창고 입고 검수 / 포워더 출고 및 반입 확인)
   - Step 7: 세금계산서 및 구매확인서 (영세율 구매확인서 발급 / 영세율·일반 세금계산서 확인)
   - Step 8: 포워더 서류 전달 및 종결 (포워더 앞 CI, PL, 수출면장 전달 / 오더 종결)
2. **공급 브랜드사 마스터 관리 (Brand Management)**
   - 브랜드명, 공급법인, 담당자 연락처/이메일, 정산 계좌, 과세 유형(영세율/과세), 제공 가능 서류(MSDS, INCI, COA 등) 통합 관리
3. **PI No.별 12대 필수 무역 서류 디지털 캐비닛 & 누락 경보**
4. **브랜드 서류 자동 요청 디스패처 (공문 & 이메일 1초 자동 생성)**
5. **아델라인 해외영업 표준 업무 매뉴얼 수록**
