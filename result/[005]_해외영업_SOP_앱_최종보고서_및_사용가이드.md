## 2. 핵심 4대 기능 구조

```
========================================================================================
                      [아델라인 해외영업 Order Process SOP 앱]
========================================================================================
   │
   ├── 📌 [탭 1] SOP 8단계 오더 파이프라인 (Kanban & Process Control)
   │     - Step 1: 바이어 주문 접수 (주문서 수령 / Draft CI 작성 / 바이어 승인)
   │     - Step 2: 브랜드사 발주 (PO 발송 / 품목·수량·금액 확정서 수령)
   │     - Step 3: 바이어 최종 확인 & 입금 요청 (Final CI / SWIFT copy / 대표님 입금 체크★)
   │     - Step 4: 브랜드사 결제 (대표님 승인 결제 / PL 수령 / Final CI/PL 대조)
   │     - Step 5: 선적서류 작성 (수출면장 발행 요청 - 패킹 확정 후 원칙 경고 배지 / CO 검토)
   │     - Step 6: 입출고 진행 (아델라인 창고 입고 검수 / 포워더 출고 / 인계 확인)
   │     - Step 7: 세금계산서 & 구매확인서 (영세율 구매확인서 / 영세 세금계산서 확인)
   │     - Step 8: 포워더 서류 전달 (Final CI, PL, 면장 인계 / 오더 종결)
   │
   ├── 📂 [탭 2] PI별 필수 서류 캐비닛 (12대 핵심 서류 무결점 체크)
   │     - 바이어 주문서, PO, 브랜드사확정서, Draft CI, Final CI, PL, Final CI/PL 합본,
   │       수출면장, SWIFT Copy, 원산지증명서(C/O), 구매확인서, 전자세금계산서
   │     - 파일 상태(미보유/검토중/완료) 트래킹 및 실시간 누락 경보 배지 연동
   │
   ├── ✉️ [탭 3] 브랜드 서류 자동 요청 센터 (Doc Request Dispatcher)
   │     - 바이어 요청 브랜드 및 서류(MSDS, INCI 영문전성분, COA, CFS, C/O 등) 선택
   │     - 1초 만에 최적화된 브랜드사용 공문/이메일 템플릿 자동 빌드
   │     - 전문 원클릭 복사 및 이메일 클라이언트(Outlook 등) 즉시 발송 연동
   │
   └── 📖 [탭 4] 아델라인 공식 SOP 매뉴얼 (Interactive Guidebook)
         - 실무 헌장, 수출면장 패킹 확정 후 발행 원칙, 영세율 처리 규정 등 상세 가이드
========================================================================================
```
