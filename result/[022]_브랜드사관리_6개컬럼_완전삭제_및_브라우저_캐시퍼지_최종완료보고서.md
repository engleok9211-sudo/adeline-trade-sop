## 4. 브라우저 캐시 완전 무력화 3중 방어막 탑재

1. **HTML `<head>` 캐시 무효화 메타태그 삽입**:
   ```html
   <meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">
   <meta http-equiv="Pragma" content="no-cache">
   <meta http-equiv="Expires" content="0">
   ```
2. **페이지 로드 즉시 구버전 스토리지 파기**:
   - `localStorage.removeItem('adeline_pipeline_master_brands')` (v1, v2, v3 일괄 파기)
   - 최신 키 `adeline_pipeline_master_brands_v4`로 격리

   - `✅ v7.0 엑셀 6개 컬럼 삭제 완료 (10대 핵심 컬럼 전용)` 녹색 뱃지를 테이블 상단에 탑재하여 본부장님께서 최신 파일 정상 열람 여부를 즉각 육안 확인 가능.
