# 🌐 [001] 해외영업 진행 프로세스(Order Process SOP) 전용 통합 관리 시스템 아키텍처 및 요구사항 정의서

- **작성일자**: 2026-11-12
- **작성조직**: AX-TWIN 전문 전술부대 (아키텍트/PM & 프로그래머)
- **승인권자**: 본부장님 (Chief Executive Officer)
- **보고라인**: ADVISOR 총괄팀장 -> 본부장님

---

## 1. 프로젝트 개요 및 배경

본 시스템은 **아델라인(Adeline)**의 글로벌 무역/수출입 거래 실무에 최적화된 **해외영업 Order Process SOP 8단계 파이프라인 관리 및 브랜드 인증 서류 디스패처 웹 애플리케이션**입니다.

바이어 발주 접수부터 브랜드사 발주, 대금 결제/수령, 수출면장 발행 및 입출고, 포워더 인계에 이르는 전 과정을 0-Error로 통제하며, 각 PI(Proforma Invoice) 번호별 필수 서류 아카이빙 및 브랜드사 인증 서류(MSDS, INCI 등) 요청 자동화를 실현합니다.

---

## 2. 핵심 3대 기능 모듈

### 모듈 1: 해외영업 SOP 8단계 파이프라인 추적 (Order Pipeline Engine)
| 단계 | 공정명 | 핵심 업무 및 검증 게이트 |
| :---: | :--- | :--- |
| **Step 1** | **바이어 주문 접수** | 바이어 주문서(Order Sheet) 수령 -> Draft CI 작성 및 전달 -> 바이어 최종 확정 접수 |
| **Step 2** | **브랜드사 발주** | 브랜드사 발주서(PO) 전달 -> 브랜드사 최종 확정서(품목, 수량, 금액) 수령 및 매칭 |
| **Step 3** | **바이어 최종 확인 & 입금 요청** | 브랜드사 확정서 반영 Final CI 작성 -> 수량/품절 변경 통보 -> 송금 요청 -> SWIFT Copy 수령 -> **아델라인 대표님 입금 체크** |
| **Step 4** | **브랜드사 결제** | 대표님 결제 승인 요청 -> 브랜드사 입금 완료 -> Packing List(PL) 수령 -> Final CI/PL 작성 |
| **Step 5** | **선적서류 작성** | Final CI/PL 바이어 전달 -> 관세사 수출면장 발행 요청 -> 원산지증명서(C/O) 발급 검토<br>*(※ 필수 원칙: 최종 패킹 확정 후 면장 발행 - 수정신고 방지)* |
| **Step 6** | **입출고 진행** | 브랜드사 -> 아델라인 창고 입고 검수 -> 포워더/지정 입고지로 출고 -> 포워더 출고 내역 최종 크로스체크 |
| **Step 7** | **세금계산서/구매확인서** | 영세율 건: 구매확인서 발급 및 영세 전자세금계산서 확인 / 과세 건: 일반 전자세금계산서 확인 |
| **Step 8** | **포워더 서류 전달** | 포워더에게 Final CI, PL, 수출면장 3대 핵심 선적서류 최종 발송 및 오더 종결(Closed) |

---

### 모듈 2: PI No. 디지털 서류 캐비닛 & 필수 파일 체크리스트
각 PI No.별로 누락 방지를 위한 12대 필수 보관 서류 등록 상태(미등록/검토중/보관완료) 관리:
1. `바이어 주문서 (Order Sheet)`
2. `브랜드사 발주서 (Purchase Order)`
3. `브랜드사 확정서`
4. `Draft Commercial Invoice (Draft CI)`
5. `Final Commercial Invoice (Final CI)`
6. `Packing List (PL)`
7. `Final CI / PL 합본`
8. `수출면장 (Export Declaration)`
9. `SWIFT Copy (입금증)`
10. `원산지증명서 (C/O) (발급 시)`
11. `구매확인서 (해당 시)`
12. `전자세금계산서 (해당 시)`

---

### 모듈 3: 바이어 요청 브랜드 & 서류 자동 요청 디스패처 (Doc Request Center)
- 바이어 국가 및 규제에 따른 필요 서류 선택 (MSDS, INCI 국영문 전성분표, COA 품질시험성적서, CFS 자유판매증명서, LOA 브랜드위임장, 위생허가증 등)
- 해당 브랜드사 담당자에게 1초 만에 발송 가능한 **공문 및 이메일 템플릿 자동 생성**
- 브랜드사별 서류 수신 상태 및 유효기간 실시간 추적

## 3. UI/UX 디자인 및 기술 아키텍처

1. **기술 스택**:
   - **Frontend**: Single-Page Application (HTML5 + Modern ES6 Modules + Tailwind CSS + Lucide Icons)
   - **Storage**: 브라우저 로컬스토리지 (LocalStorage) 영구 저장 + JSON 데이터 내보내기/가져오기(백업/복원)
   - **발열/토큰 제로 (Zero-Heat & Token-Zero)**: 빌드 도구나 무거운 런타임 없이 더블클릭 또는 브라우저 즉시 구동 가능
2. **반응형 인터페이스**:
   - 상단 KPI 대시보드 (진행중 오더, 입금 대기, 선적 대기, 서류 누락 경보)
   - 탭 네비게이션: `[오더 파이프라인 (SOP 8단계)]` / `[PI별 서류 캐비닛]` / `[브랜드 서류 요청 센터]` / `[SOP 업무 가이드북]`
   - 인터랙티브 모달: 신규 PI 생성, 단계별 체크리스트 팝업, 이메일 자동 생성기
